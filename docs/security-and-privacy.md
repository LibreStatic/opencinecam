# Security and Privacy

The portable OSS app has no analytics, telemetry, account, remote crash reporting, or cloud sync, and uploads nothing unless the user opts in to WebDAV transfers to their own server. Required permissions are CAMERA; optional RECORD_AUDIO; FOREGROUND_SERVICE plus camera/microphone service permissions; and POST_NOTIFICATIONS where required. INTERNET and ACCESS_NETWORK_STATE are declared only for opt-in WebDAV transfers (OCC-PLAN-067, ADR-0034), FOREGROUND_SERVICE_DATA_SYNC only for their opt-in *Upload new takes automatically* switch (a visible WorkManager `dataSync` foreground service; WorkManager's library manifest adds RECEIVE_BOOT_COMPLETED and WAKE_LOCK), and ACCESS_COARSE/FINE_LOCATION only for opt-in geotagging; all are off by default and presets never enable them. OCC-PRIV-001 and ADR-0027 (both amended 2026-09-26) allow network and location permissions only for these named opt-in features, and the 2026-10-19 amendments to OCC-PRIV-001 and ADR-0034 allow background network use only for that automatic upload: takes recorded after the switch was turned on, on Wi-Fi unless cellular is allowed, paused while recording. There is otherwise no background or automatic network use, no analytics/telemetry/accounts, HTTPS-only transfers and no third-party SDKs; any other network, location or sensitive permission fails the `SecurityAudit` host test over the real manifest. No broad storage permission is used.

The service and providers are non-exported unless a documented share surface requires otherwise. PendingIntents are immutable. Shares use content URIs, explicit MIME types, temporary read grants, and chooser UI. MediaStore and SAF descriptors are closed by their owner. Signing keys and Play credentials stay outside the repository.

Capability and diagnostic exports warn about fingerprint, model, camera/codec identifiers, file names, timestamps, and failure context. Redacted export is default; full export is explicit. Logs rotate locally, omit per-frame metadata in release, and are deleted by user action or retention policy.

Dependency verification, SBOM, SPDX notices, secret scanning, exported-component inspection, backup policy, native hardening, and malformed schema/container fuzzing are release gates. F-Droid, direct, and Play artifacts use identical portable runtime behavior and no proprietary service dependency.
